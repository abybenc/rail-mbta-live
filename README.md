# Rail Live

A personal, installable web app for MBTA Commuter Rail:

- Trip planner between any two Commuter Rail stations
- Live train tracking (current position between stations, speed, GPS age)
- Delays, cancellations and track numbers from the MBTA V3 live API
- Saved routes, nearest-station search, works as an Android home screen app

Data: [MBTA V3 API](https://api-v3.mbta.com). Not affiliated with the MBTA.

## Install on Android
Open the GitHub Pages link in Chrome, tap the menu, then **Install app**.

## API key (optional)
The app works without a key (about 20 requests per minute). For more, get a free key at api-v3.mbta.com and paste it in the app's Settings.
